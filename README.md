## 📌 Descrizione

**Web Gestionale Affitto** è sviluppata con **Flask**, **MongoDB** e deployata su **Docker**

Il gestionale consente di registrare e amministrare i contratti, generare ricevute in formato PDF, consultare lo storico dei pagamenti e importare o esportare i dati in formato CSV.

## ✨ Funzionalità

### Contratti di locazione

- Inserimento di nuovi contratti
- Visualizzazione dell'elenco dei contratti
- Modifica dei dati contrattuali
- Archiviazione e ripristino dei contratti
- Eliminazione del contratto e delle ricevute collegate
- Gestione dei dati di locatore, conduttore e immobile

### Ricevute d'affitto

- Creazione di ricevute associate a uno specifico contratto
- Calcolo automatico dell'imponibile, dell'IVA e del totale
- Numerazione progressiva per contratto
- Generazione di ricevute PDF in formato A5
- Produzione della copia per il conduttore e della copia per il locatore
- Visualizzazione e filtro delle ricevute per anno
- Modifica, ristampa ed eliminazione delle ricevute

### Importazione ed esportazione

- Esportazione dei contratti e delle ricevute in file CSV
- Download dei CSV all'interno di un archivio ZIP
- Importazione dei dati da file CSV
- Verifica della struttura e delle intestazioni dei file importati


> Le funzionalità disponibili dipendono dalla versione corrente dell'applicazione.

## 🚀 Installazione

### Configurazione delle variabili d'ambiente

L'applicazione utilizza le seguenti variabili d'ambiente:

| Variabile | Descrizione | Esempio |
| --- | --- | --- |
| `MONGO_INITDB_ROOT_USERNAME` | Utente amministratore MongoDB | `gestionale_user` |
| `MONGO_INITDB_ROOT_PASSWORD` | Password MongoDB | `password_lunga_e_casuale` |
| `MONGO_HOST_NAME` | Host del servizio MongoDB | `mongo_web_gestionale_affitto` |
| `MONGO_PORT` | Porta MongoDB | `27017` |
| `SECRET_KEY_SESSION` | Chiave usata da Flask per firmare la sessione | valore casuale sicuro |

Puoi generare una chiave sicura con:

```bash
python -c 'import secrets; print(secrets.token_hex())'
```

### Esecuzione di docker-compose

Installa Docker seguendo la seguente [Documentazione](https://docs.docker.com/engine/install/)

Esegui il seguente file compose

```yaml
services:
  web:
      image: lucianobalzano/web_gestionale_affitto
      environment:
          MONGO_INITDB_ROOT_USERNAME: example
          MONGO_INITDB_ROOT_PASSWORD: example
          MONGO_HOST_NAME: mongo_web_gestionale_affitto
          MONGO_PORT: 27017 
          SECRET_KEY_SESSION: b'YOUR_SECRET_KEY'
      ports:
        - "5000:5000"
      depends_on:
        - mongo
  
  mongo:
    image: mongo
    hostname: mongo_web_gestionale_affitto
    environment:
      MONGO_INITDB_ROOT_USERNAME: example
      MONGO_INITDB_ROOT_PASSWORD: example
    ports:
      - "27017:27017"
    volumes:
      - ./mongo_data:/data/db
```


## 🛠️ Tecnologie

- **Python**
- **Flask** per l'applicazione web
- **MongoDB** per la persistenza dei dati
- **PyMongo** per l'accesso al database
- **Pandas** per l'importazione dei file CSV
- **ReportLab** per la generazione delle ricevute PDF
- **Docker** e **Docker Compose** per l'esecuzione dei servizi

## 📂 Struttura del progetto

```text
.
├── application.py       # Applicazione Flask e definizione delle route
├── contratto.py         # Modello e operazioni sui contratti
├── ricevuta.py          # Modello, calcoli e operazioni sulle ricevute
├── user.py              # Gestione dell'utente e autenticazione
├── crypto.py            # Funzioni di hashing della password
├── db_manager.py        # Connessione e operazioni MongoDB
├── data_manager.py      # Formattazione ed estrazione delle date
├── file_manager.py      # Import/export CSV e generazione dei PDF
├── ric_create.py        # Layout ReportLab delle ricevute A5
├── finicial.py          # Calcoli IVA e conversione degli importi in lettere
├── requirements.txt     # Dipendenze Python
├── compose.yml          # Servizi web e MongoDB
├── templates/           # Template HTML di Flask
├── static/              # Risorse CSS, JavaScript e immagini
└── mongo_data/          # Dati persistenti MongoDB, se creati localmente
```


## 💡 Obiettivo del progetto

L'obiettivo di **Web Gestionale Affitto** è realizzare uno strumento intuitivo per organizzare le informazioni relative alla gestione degli affitti, riducendo la necessità di utilizzare strumenti separati per immobili e pagamenti.
